# Retros

Post-session reflection documents. One file per retro, named `YYYY-MM-DD-{topic-slug}.md`. Each covers what happened, what worked, what did not, what surfaced, and next actions. The protocol is in `~/.agents/agents-md-detail/workflow-rituals/retro.md`.

Earlier retros are in [`../retro/`](../retro/) and [`../swain-retro/`](../swain-retro/), left in place. Put new ones here.
