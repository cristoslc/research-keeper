# Plans

Implementation plans: what to build, in what order, and with what constraints. A plan may reference ADRs or specs.

## Lifecycle

- Delete a plan once it is fully implemented and merged. A plan is fully implemented when all its tasks are done.
- Delete a plan that is superseded by a newer one, or abandoned.
- When a branch finishes, delete the plans it completed and the musings it acted on.

Older plans from before this rule remain here, including a `Completed/` folder. Treat them as history; remove them when you next touch the area.
