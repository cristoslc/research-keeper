# Musings

Pre-artifact thought capture: raw ideas, half-formed concepts, and exploratory notes that may later become ADRs, plans, or other documents. Files are freeform markdown with no required structure. A musing is less structured than a plan, and a plan is less structured than an ADR.

## Rules

- Commit and push a musing as soon as you write it. The agent instructions in [`AGENTS.md`](AGENTS.md) say the same.
- Delete a musing once its content has been acted on (turned into a plan, an ADR, or code).
