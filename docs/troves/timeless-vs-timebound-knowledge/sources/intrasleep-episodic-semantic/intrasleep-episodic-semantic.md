# Memory Architectures Explained: Episodic vs Semantic Storage

## Key distinctions

- **Episodic memory**: encodes specific experiences — what, where, when. Binds contextual details (spatial location, emotions, sequences) into holistic traces. Hippocampus-dependent, especially during REM. Vulnerable to forgetting.
- **Semantic memory**: stores general knowledge divorced from personal context. More stable, less prone to forgetting. Distributed across cortical areas. Abstracts knowledge from specific contexts.

## The transformation pipeline

1. **Encoding**: episodic memories facilitate semantic learning. Repeated experiences accumulate into factual knowledge.
2. **Retrieval**: semantic memory scaffolds recalling episodic details by providing a framework or schema.
3. **Transformation**: over time, episodic memories transform into semantic memories as contextual details fade but core facts persist. This is consolidation.

## Sleep-dependent consolidation

Diekelmann & Born (2010): sleep-dependent consolidation strengthens both episodic and semantic memories, enabling better retention and abstraction. Dream content, drawing from recent episodic fragments, may serve as a cognitive mechanism by replaying and integrating memories.

## Why semantic knowledge is more stable

Semantic memory abstracts knowledge from specific contexts, making it less vulnerable to forgetting than event-bound episodic memories. This is the cognitive science justification for why the claims database (semantic) should outlast the individual source files (episodic).
