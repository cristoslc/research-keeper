# Memory Consolidation

Squire, Genzel, Wixted, Morris (2015). Cold Spring Harb Perspect Biol. 7(8):a021766.

## The core model

Systems consolidation: memories initially dependent on the hippocampus are reorganized over time so the hippocampus becomes less important and a more permanent memory develops in distributed regions of the neocortex. Information is encoded in BOTH hippocampus and neocortex at learning time — consolidation is about strengthening and connecting the neocortical representation, not transferring.

## Schema-accelerated consolidation

The rate of consolidation depends on the amount of **preexisting knowledge** (schema) relevant to the new information.

Tse et al. (2007): Rats learned paired associates over 6 weeks, building a spatial schema. Once the schema existed, new paired associates consolidated within 48 hours (vs. weeks without the schema). When lesions were made only 3 hours after training with a schema, memory was poor. At 2 days, memory was good — rapid consolidation into existing schema.

**Implication for rk**: sources ingested into a topic that already has rich prior knowledge should consolidate (become "timeless" / semantic) faster than sources in a novel domain.

## Episodic-to-semantic transformation

Multiple-trace theory / transformation hypothesis: episodic memories that retain contextual details remain hippocampus-dependent. Consolidation into neocortex involves **loss of time and place information** and transition to gist-based, fact-like semantic memory. Episodic memories transform into semantic memories as contextual details fade but core facts persist.

This is the biological analogue of rk's "stale → forgotten" transition: the specific context of when you read a source fades, but the durable claims persist as semantic knowledge.

## Neural replay and sleep

Neural replay occurs during slow-wave sleep and quiet wakefulness. The hippocampus replays recent patterns, training neocortical regions. This is the mechanism behind "sleep-time computation" / `rk dream`. Replay strengthens hippocampal-cortical connectivity; blocking it impairs learning.

## Consolidation speed variable

Not all memories consolidate at the same rate. Variables:
- Amount of preexisting knowledge (schema acceleration)
- Emotional significance
- Repetition frequency
- Hippocampal-cortical connectivity at encoding

There is no fixed consolidation timeline — it varies by content and context. This argues against a single TTL and for adaptive, context-sensitive TTL assignment.
