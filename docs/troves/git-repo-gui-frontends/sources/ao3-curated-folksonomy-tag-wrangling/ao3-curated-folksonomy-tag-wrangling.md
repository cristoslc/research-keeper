# The Past, Present, and Hopeful Future for Tags and Tag Wrangling on the AO3

Published 2012-12-15 by the AO3 Tag Wrangling Committee.

The question has been raised in various places of how sustainable the Archive of Our Own's tag wrangling system is, and whether it will continue to be viable as AO3 continues to grow and the number of fandoms and tags increases.

## Why Do AO3 Tags Work Like They Do?

The AO3 tag wrangling system was specifically designed as a compromise between the two standard tagging/organization models for online archives: a regulated taxonomy, versus a 'folksonomy'.

**A regulated taxonomy** -- such as what's currently used on fanfiction.net -- allows creators to tag their work with a limited number of pre-determined options (such as genre or characters). This system is very good for keeping things ordered and preventing misspellings and otherwise inconsistent labeling. However, it also requires constant maintenance to add new tags as new fandoms arise, and greatly restricts what users can label or sort by.

**A "folksonomy"** -- the tagging system used on most social bookmarking sites and Tumblr -- allows users to tag their content with any tag of their choosing, and users can see all works using any given tag. This system has the advantage of flexibility and currentness -- its tags are always up-to-date with user preferences -- but can make browsing difficult. (For example: on Tumblr, if you want to see most posts about kid!Loki, you also have to look up "kid loki" and "bb!Loki" and will still miss the posts tagged "bbloki".)

## The AO3 Compromise: Curated Folksonomy

The AO3 solution: let users enter whatever tags they like, and display all those tags however the creator or bookmarker wants to display them. Then, behind the scenes, volunteers can organize and link tags together so the most commonly used and useful-for-browsing concepts are more readily available to the largest number of people -- both creators and audience -- with the smallest amount of required effort. This is how the AO3 tag wrangling system works.

## Options Considered and Their Drawbacks

1. **Limit to approved tags only** -- puts burden on users to request new tags; requires wranglers to work quickly; many users wouldn't bother tagging if their tag wasn't available
2. **Approve before display** -- wranglers become inadvertent gatekeepers of what tags are shown; still requires enormous volunteer team
3. **Let users enter anything, moderate afterward** -- burden on moderators would be considerable for 500K+ works
4. **No organization at all** -- users must search for every permutation of a concept (frustrating for browsers who don't know all variants)

## Sustainability

After observing wrangling on the beta archive over four years, the committee believes the system is sustainable long-term:

- Volunteer pool is as large as it's ever been (~160 wranglers) and growing
- Archive growth doesn't correspond directly to increased wrangling work
- The vast majority of new works fall into very small fandoms (under 20 works, occasional wrangling) or very large fandoms (best-wrangled, most volunteers)
- Even large fandoms may not produce many new tags -- a popular fandom with a small core cast may get 100 new works/day but only one new relationship tag
- Many fandoms share tags (e.g., X-Men metatag has 13 sub-fandoms with overlapping characters/relationships)

## Key Design Principles

- Unwrangled tags still function like Tumblr/Pinboard tags (showing all works with that tag)
- AO3 search works for both wrangled tags and text of unwrangled tags
- If all wrangling stopped, existing connections would be preserved and new tags would still be as useful as tags on any flat-tagging platform
- Tag categories (fandom, character, relationship, freeform) can be viewed and wrangled independently
- Wranglers can sort tags by number of uses to prioritize

## Future Directions

- Better internationality support (linking tags across languages)
- Additional Tags (freeforms) management improvements
- Opening aspects of the wrangler interface to regular users
- Allowing users limited wrangling capabilities (sorting tags into fandoms, making synonyms, suggesting canonical tags)
