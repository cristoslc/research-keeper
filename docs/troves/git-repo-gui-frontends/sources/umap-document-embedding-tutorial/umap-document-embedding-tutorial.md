# Document embedding using UMAP

This is a tutorial of using UMAP to embed text (but this can be extended to any collection of tokens). We are going to use the 20 newsgroups dataset which is a collection of forum posts labelled by topic. We are going to embed these documents and see that similar documents (i.e. posts in the same subforum) will end up close together. You can use this embedding for other downstream tasks, such as visualizing your corpus, or run a clustering algorithm (e.g. HDBSCAN). We will use a bag of words model and use UMAP on the count vectors as well as the TF-IDF vectors.

## Setup

```python
import pandas as pd
import umap
import umap.plot
from sklearn.datasets import fetch_20newsgroups
from sklearn.feature_extraction.text import CountVectorizer, TfidfVectorizer
import matplotlib.pyplot as plt
from bokeh.plotting import show, save, output_notebook, output_file
from bokeh.resources import INLINE
output_notebook(resources=INLINE)
```

The dataset contains 18846 documents across 20 categories. Categories include things like 'comp.sys.ibm.pc.hardware', 'rec.sport.baseball', 'sci.med', 'talk.politics.mideast', etc.

## Using raw counts

We use a bag-of-words approach and construct a word-document matrix using sklearn's CountVectorizer:

1. Split the text into tokens by splitting on whitespace
2. Remove english stopwords (the, and, etc)
3. Remove all words which occur less than 5 times in the entire corpus

This gives a 18846x34880 sparse matrix (18846 documents, 34880 unique tokens).

We use UMAP to reduce from 34880 dimensions to 2 dimensions using **Hellinger distance**, which measures the similarity between two probability distributions. Each document has a set of counts generated by a multinomial distribution.

```python
embedding = umap.UMAP(n_components=2, metric='hellinger').fit(word_doc_matrix)
```

Processing time: ~2 minutes for 18846 documents.

The resulting plot shows reasonable separation -- groups that you would expect to be similar (such as 'rec.sport.baseball' and 'rec.sport.hockey') are close together. The big clump in the middle corresponds to extremely similar newsgroups like 'comp.sys.ibm.pc.hardware' and 'comp.sys.mac.hardware'.

## Using TF-IDF

TF-IDF gives less weight to words that appear frequently across a large number of documents (they are more popular in general) and asserts higher weight to words that appear frequently in a smaller subset of documents (they are probably important for those documents).

```python
tfidf_vectorizer = TfidfVectorizer(min_df=5, stop_words='english')
tfidf_word_doc_matrix = tfidf_vectorizer.fit_transform(dataset.data)
tfidf_embedding = umap.UMAP(metric='hellinger').fit(tfidf_word_doc_matrix)
```

Results look fairly similar to raw counts but this can be a useful trick to have in your toolbox.

## Potential applications

Now that we have an embedding, what can we do with it?

* **Explore/visualize your corpus** to identify topics/trends
* **Cluster the embedding** to find groups of related documents
* **Look for nearest neighbours** to find related documents
* **Look for anomalous documents**

### Interactive visualization note

For interactive plotting, UMAP provides:
```python
f = umap.plot.interactive(embedding, labels=dataset.target, hover_data=hover_df, point_size=1)
show(f)
```

This creates an interactive Bokeh plot where you can hover over points to see their category labels, zoom in on clusters, and explore the document space visually.
