# Tag Filtering and Multi-tag Selection

## Feature Request on Raindrop.io (marked as "complete")

### Original Request (by Andrei, June 2022)

I did not fully grasp the power of tags until I started working more seriously with Zotero. It would be great if raindrop.io could support a similar filtering functionality.

When filtering based on a specific tag, the list of available tags would be reduced to only contain the tags contained by the filtered bookmarks.

For example, I currently have a total of 150 tags in the left pane. If I select any one tag, the list of tags does not change and it still maintains the same 150 tags, even though the filtered bookmarks do not contain all of them. It would be great if when one selects a tag, the list of tags gets filtered to contain only tags present in the filtered bookmarks. The Tag list would then get filtered down to a smaller number and would continue to filter down as additional tags are selected in the filtering process.

### Community Discussion (key merged requests)

**Improved search through a dynamic tags list (by overbyte, June 2025):**
One of the main problems with knowledge management software is its success. If it's easy to create/save content and the app finds some utility in your life, you'll end up with thousands and thousands of entries. Trying to surface contextual content can be confusing.

Proposal: when typing a #tag in the search box, have the Tags list in the sidebar reduced/filtered to tags that are associated to the #tag in the search box. So when I type #shopping in the search box, all my bookmarks with the #shopping tag would be scanned for all other tags. The Tags list now becomes a source of information to help me surface the content that I seek.

"I currently have 945 tags. Trying to find relevant tags during a search is tedious and time consuming."

**Multi-tag selection by clicking (by 16wsohn, May 2025):**
Multi-tag search can be done in a search bar, but it would be nice if this can be conveniently done by clicking the multiple tags (for example by Ctrl + clicking) in the tag pane.

**Additive tag searches with modifier key (by Aidan Whitehall, April 2023):**
At present, searching by clicking on a bookmark tag causes the clicked tag to replace the current one. Please add a keyboard modifier to enable the user to add the clicked tag to the current one. This would quickly narrow down search results.

**Checkbox style filtering (by Miguel Alonso, February 2024):**
When entering a collection, it is currently possible to filter the results by typing the desired tags on the search bar. However, I usually find this quite tedious. A checkbox styled menu to activate/deactivate tags within the collection would be much smoother.

**Ronald Richard's vision (December 2023):**
Clicking on a single tag result, such as 'business', could filter out content that isn't attached to that choice. Then we would be presented with a list of tags that share content with our original choice, such as 'financial'. We click on 'financial' and the list is reduced to notes that only contain the 'business' and 'financial' tags. We could keep choosing tags until our search is complete. It would be like a simple query system. The query could then be saved as the filter for a new collection/folder that would continue to capture content based on the criteria.

### Status Response (Rustem Mussabekov, Raindrop.io team, December 2024)

Marked as complete. "When filtering based on a specific tag, the list of available tags would be reduced to only contain the tags contained by the filtered bookmarks -- This is exactly how filtering works right now."

### Pushback (kriswilk, June 2025)

"This should NOT have been marked as complete. Although the tag search can be narrowed by typing more tags in the search box, most of the suggestions in this thread are about offering OTHER ways to progressively filter existing searches by additional tags. For instance: Initial search for a tag should reduce the MAIN tag list to show only the tags present on the results. When reviewing search results, clicking on a tag should add that tag to the search and narrow the search even further."

This "drill-down" mechanism would be a natural and efficient way to find bookmarks, even with vast numbers of tags.
