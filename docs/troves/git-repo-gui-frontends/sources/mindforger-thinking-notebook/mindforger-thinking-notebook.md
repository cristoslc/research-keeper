# MindForger - Thinking Notebook

Are you drowning in information, but starving for knowledge?

MindForger is a human mind inspired personal knowledge management tool.

## Core Principles

### Human Mind

MindForger aims to mimic human mind -- learning, recalling, recognition, associations, forgetting -- in order to achieve synergy with your mind to make your searching, reading and writing more productive.

### Personal

MindForger ensures that you own your personal data. It respects privacy and enables security of your knowledge.

### Knowledge

MindForger seeks knowledge hidden in your remarks to enable its mining.

### Management

MindForger starts where editors and search engines end. It thinks as you search, browse, read and write. Once you find a remark, MindForger brings its associations. As you browse notes and read them it looks up related relevant knowledge in your notebooks. If you edit a remark, MindForger brings associations as you write. It reminds you about existing content related to the text being written.

### Tool

MindForger is a desktop application for Linux (also available on Windows, macOS, and via Docker).

## Key Features

- **Knowledge Graph Navigator** - Navigate your knowledge as an interactive graph, including tag-based navigation
- **Refactoring** - IDE-style features for notes: clone, promote, demote, move, extract, refactor within one or across different Markdown files
- **Stencils** - Templates for quick creation of various notebook types (meeting minutes, software analysis, SMARTER goals, GROW model)
- **Analytics** - Metrics and integrity checks; Markdown files can be analyzed with text analysis and mining tools
- **Synchronization** - Data sync among devices using SCM (Git, GitHub, BitBucket) and/or cloud drives
- **Sharing** - Securely share MindForger repositories or Markdown files using SSH and remote Git repositories
- **Backup** - Compressed archives, incremental backup to remote SCM or cloud drives
- **Full-text search** - Search across all notebooks
- **Eisenhower matrix** - Priority management
- **PDF library** - Import and manage PDF documents
- **Math support** - Mathematical notation rendering
- **I18n** - Internationalization support
- **Wingman** - AI assistant integration

## Technical Details

- **Open source** (FOSS) -- source code on GitHub, uses open formats (Markdown)
- **Free** -- licensed under free software license, no cost
- **Performance** -- handles 1000s of sections and 100s of files, parsed and indexed instantly
- **Privacy** -- stores data locally, does not upload anything anywhere
- **Security** -- repositories can be encrypted (e.g., using ecryptfs)
