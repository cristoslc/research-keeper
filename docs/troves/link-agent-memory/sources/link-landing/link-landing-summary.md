# Summary: Link Landing Page

**Source:** https://gowtham0992.github.io/link/

**Why selected:** The homepage is the definitive one-paragraph statement of Link's
positioning and core value proposition. It is the source against which research-keeper's
own PURPOSE.md should be compared.

**What it says:** Link is "local memory for AI agents." The three headline promises are:
(1) automatic injection of memory at session start and proposal of new memory at session
end (human approves every save), (2) plain Markdown on the user's machine with no cloud,
shared across Claude Code, Codex, Cursor and more, and (3) temporal truth — conflicting
memories are replaced with lineage kept, and recall can answer what was true on any past
date (`--as-of`).

The page leads with a benchmark claim (84.8% on LoCoMo, all 1,540 questions, under mem0's
own harness, beating mem0's cloud platform scored by the same judge, confirmed by a second
independent judge). This "measured, not asserted" framing is a deliberate trust posture
repeated across the docs site.

**Aspects covered:** positioning, value proposition, benchmark stance, install surface,
cross-agent sharing, temporal memory.

**Relevance to trove topic (agent memory / local-first):** Establishes the "product surface"
— what agents experience. It frames memory as something that shows up *on its own* (hooks)
rather than something the user must remember to query. This is the primary contrast point
with research-keeper, which is retrieval-driven (agent queries on demand) rather than
injection-driven (memory pushed in at session start).
